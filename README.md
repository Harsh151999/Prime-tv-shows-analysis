# Prime Video TV Shows — Data Analysis

An end-to-end data analysis project on Amazon Prime Video's TV show catalogue: raw data is cleaned, loaded into SQLite, queried with SQL, and turned into a 9-section visual PDF report plus an interactive HTML dashboard.

**Stack:** Python · SQLite · pandas · matplotlib · seaborn · NumPy

## Dataset

| | |
|---|---|
| Source file | `Prime_TV_Shows_Analysis (1).xlsx` |
| Shows | 395 |
| IMDb-rated | 223 |
| Avg IMDb (rated) | 7.39 |
| Languages | 14 |
| Avg seasons | 2.6 |
| Columns | Title, Year, Seasons, Language, Genre, IMDb rating, Age rating |

## What the script does (`prime_tv_analysis.py`)

1. **Load & clean** — reads the Excel sheet, coerces types, buckets shows into release-year eras (pre-2000 → 2018–20) and IMDb rating bands.
2. **SQLite + SQL** — writes the cleaned data to `prime_tv.db` and runs 10 queries: top/bottom rated shows, avg IMDb by genre/language/age rating/era, season-longevity bands, seasons-vs-rating correlation, language × genre combos, and rating-band distribution.
3. **Visualize → PDF** — renders a 9-section report to `Prime_TV_Analysis_Report.pdf`:
   - Cover page with headline stats
   - Language analysis (volume + avg rating)
   - Genre analysis (bar chart + volume-vs-quality bubble chart)
   - IMDb rating distribution (histogram + band chart)
   - Age rating breakdown (pie + bar)
   - Release-year trend (content growth + rating by era)
   - Seasons & longevity (season bands + seasons-vs-rating scatter with trendline)
   - Top 15 / bottom 10 rated shows
   - Language × genre heatmap
   - Key insights summary page

## Key findings

- **Language:** English dominates at 79% (314/395 shows); Hindi is second at 10%.
- **Genre:** Sci-fi has the highest avg IMDb (8.03) but only 4 rated shows; Drama (66 shows, 7.62 avg) offers the best balance of volume and quality.
- **Growth:** 2018–2020 alone added 177 shows — more than every prior era combined.
- **Ratings:** 77% of rated shows score 7+; distribution is right-skewed. Top-rated: *Malgudi Days* (9.5).
- **Age rating:** 58% of content is rated 13+ or 16+; family-friendly content is only 24%.
- **Longevity:** 45% of shows run just 1 season; average is 2.6 seasons, longest runs to 20.

## Running it

```bash
pip install pandas matplotlib seaborn numpy openpyxl
python prime_tv_analysis.py
```

> Note: the script's `EXCEL_PATH`, `DB_PATH`, and `OUT_PDF` are currently hardcoded to sandbox paths (`/mnt/user-data/...`, `/home/claude/...`). Update these three constants at the top of the file to local paths before running.

## Limitations

- Sample of 395 shows — not a full catalogue snapshot, so findings may not generalize.
- No documented source/date for the underlying scrape or export.
- Genre/language groupings use the dataset's own labels as-is, with no normalization for near-duplicates.
